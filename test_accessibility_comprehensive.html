🎹 Keyboard Navigation Testing

Keyboard Shortcuts to Test

  • Tab Navigate to copy buttons
  • Shift + Tab Navigate backwards
  • Enter Activate copy button
  • Space Activate copy button
  • Escape Blur focused element
  • Ctrl + ↑ Navigate to previous code block
  • Ctrl + ↓ Navigate to next code block

Keyboard Navigation Checklist

  • Copy buttons are focusable with Tab key
  • Focus indicators are clearly visible
  • Enter and Space keys activate copy functionality
  • Escape key removes focus from buttons
  • Arrow key navigation works between code blocks
  • Skip links are available for keyboard users
  • Focus order is logical and predictable

def calculate_fibonacci(n):
    """Calculate the nth Fibonacci number."""
    if n <= 1:
        return n
    return calculate_fibonacci(n-1) + calculate_fibonacci(n-2)

# Example usage
result = calculate_fibonacci(10)
print(f"The 10th Fibonacci number is: {result}")
JavaScript 
                    
class AccessibilityHelper {
    constructor() {
        this.announcer = document.getElementById('announcements');
    }
    
    announceToScreenReader(message) {
        if (this.announcer) {
            this.announcer.textContent = message;
            setTimeout(() => {
                this.announcer.textContent = '';
            }, 1000);
        }
    }
    
    setupKeyboardNavigation() {
        document.addEventListener('keydown', this.handleKeyDown.bind(this));
    }
    
    handleKeyDown(event) {
        // Handle keyboard navigation
        switch (event.key) {
            case 'Enter':
            case ' ':
                if (event.target.classList.contains('copy-btn')) {
                    event.preventDefault();
                    this.copyCode(event.target);
                }
                break;
        }
    }
}

🔊 Screen Reader Testing

Screen Reader Testing Instructions

Test with screen readers like NVDA (Windows), JAWS (Windows), VoiceOver (macOS), or Orca (Linux):

  • Navigate through the page using screen reader commands
  • Verify that code blocks are announced with their language
  • Check that copy buttons have descriptive labels
  • Test that copy actions are announced to users
  • Verify skip links work for navigation

Screen Reader Compatibility Checklist

  • Code blocks are announced as "regions" with language info
  • Copy buttons have descriptive ARIA labels
  • Copy success/failure is announced to users
  • Skip links are available and functional
  • Live regions announce important changes
  • Language indicators are read correctly
  • Code content is readable and navigable

🎨 Color Contrast Testing

Contrast Testing Instructions

Verify that all text meets WCAG 2.1 contrast requirements:

  • AA Normal Text: 4.5:1 contrast ratio minimum
  • AA Large Text: 3:1 contrast ratio minimum
  • AAA Normal Text: 7:1 contrast ratio minimum
  • AAA Large Text: 4.5:1 contrast ratio minimum

Contrast Testing Checklist

  • Copy button text meets contrast requirements
  • Code content text is readable
  • Language indicators have sufficient contrast
  • Focus indicators are clearly visible
  • Success/error states maintain contrast
  • Inline code has adequate contrast
  • High contrast mode is supported

🔆 High Contrast Mode Testing

High Contrast Testing Instructions

Enable high contrast mode in your operating system and verify:

  • Windows: Settings → Ease of Access → High contrast
  • macOS: System Preferences → Accessibility → Display → Increase contrast
  • Browser: Use developer tools to simulate prefers-contrast: high

High Contrast Mode Checklist

  • All text remains readable in high contrast mode
  • Focus indicators are enhanced and visible
  • Copy button states are clearly distinguishable
  • Code syntax highlighting adapts appropriately
  • Borders and outlines are more prominent
  • Background colors provide sufficient contrast

🎭 Reduced Motion Testing

Reduced Motion Testing Instructions

Enable reduced motion preferences and verify animations are disabled:

  • Windows: Settings → Ease of Access → Display → Show animations
  • macOS: System Preferences → Accessibility → Display → Reduce motion
  • Browser: Use developer tools to simulate prefers-reduced-motion: reduce

Reduced Motion Checklist

  • Copy button transitions are disabled
  • Hover effects are simplified or removed
  • Focus changes don't include animations
  • Success/error state changes are instant
  • All functionality remains available
