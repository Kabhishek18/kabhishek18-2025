Keyboard Navigation Test - Simplified Code Blocks

Keyboard Navigation Instructions

This page tests Task 7.1: Keyboard navigation support for code blocks.

  • Tab - Navigate to copy buttons
  • Enter or Space - Activate copy button
  • Ctrl/Cmd + ↓ - Navigate to next code block
  • Ctrl/Cmd + ↑ - Navigate to previous code block
  • Escape - Blur focused copy button

Screen Reader Users: Code blocks are announced with language information and copy status updates.

Python Example

Python 
def hello_world():
    """A simple hello world function."""
    print("Hello, World!")
    return "success"

# Call the function
result = hello_world()
print(f"Function returned: {result}")

JavaScript Example

JavaScript 
function greet(name) {
    // Greet a person by name
    console.log(`Hello, ${name}!`);
    return true;
}

// Usage example
const success = greet("World");
console.log("Greeting successful:", success);
